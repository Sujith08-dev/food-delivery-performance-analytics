# Food Delivery Performance Analytics Dashboard

An end-to-end data analytics project analyzing food delivery
operations using Python, Pandas and Microsoft Power BI.

## Project Overview

The project uses 45K+ food delivery records to analyze delivery
performance and identify patterns related to traffic, vehicle type,
weather conditions, festivals and multiple deliveries.

## Tech Stack

- Python
- Pandas
- Microsoft Power BI
- DAX
- Data Cleaning
- Data Visualization

## Key Metrics

- Total Orders: ~8K
- Average Delivery Time: 28.92 minutes
- Average Rating: 4.66/5
- Delivery Persons: ~1K

## Key Insights

- Higher traffic density is associated with longer delivery times.
- Orders involving multiple deliveries show substantially higher
  average delivery times.
- Festival orders show higher average delivery times than
  non-festival orders.
- Average ratings remain around 4.6–4.7 across the displayed
  order types.
